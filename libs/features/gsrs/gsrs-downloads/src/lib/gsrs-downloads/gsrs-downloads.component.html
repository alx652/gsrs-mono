GSRS v3.2.0 (July 2026)
CHANGELOG

The GSRS 3.2.0 software release is a minor release. The biggest changes we have made are large-scale efforts that make GSRS more secure and maintainable, but in the user interface, the difference will be minimal.

The biggest changes were:
  • Changing user roles architecture
  • Upgrading the version of the Angular framework used by the frontend.

The update to user roles touches many areas of the software, but is mainly out-of-sight for most users. Similarly, the upgrade to Angular provides greater security, but most of the applications will look very similar to most users. Other improvements and bug fixes are also included in this version; selected highlights are listed below.

Highlighted changes include:
  • User Role architecture change
  • Frontend Angular 13 to 20 Update
  • Updated Product Module
  • Updated Application Module
  • Updated Impurities Module
  • Updated In Vitro Pharmacology Module
  • Updated Advanced Search
  • Updated Specified Substance Group 4 - Manufacturing Module
Highlighted improvements and bug fixes include:
  • Fix to a minor problem that impacted indexing
  • Fix Submit and Status Date validation in Application
  • Fix Import JSON in Register Impurities
